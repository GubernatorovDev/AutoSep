# Установка личного VPN на VPS

Запустите один скрипт. Он установит 3x-ui, настроит VLESS + gRPC + REALITY и создаст профиль для подключения.

## 1. Создайте VPS и получите данные для входа

Выберите чистый VPS с публичным IPv4 и systemd. Подойдёт **Ubuntu 22.04 или 24.04 LTS** либо **Debian 12 или 13**. Поддерживаются x86_64 и aarch64.

Начните с Франкфурта или Амстердама. Для проверки соединения сервер можно арендовать на несколько часов.

| Локация Aéza | Цена в месяц |
| --- | ---: |
| Франкфурт (Германия) и Амстердам (Нидерланды) | от 593 ₽ |
| Стокгольм | от 239 ₽ |
| Хельсинки, Варшава, Шарлотт, Париж и Вена | от 593 ₽ |
| Лондон | от 1 022 ₽ |

Сервер можно арендовать на несколько часов, дней или недель. Итоговую цену для выбранной локации и срока смотрите при оформлении. [Выбрать сервер в Aéza](https://aeza.ru/?ref=490776)

После запуска найдите публичный IPv4 и логин SSH в карточке сервера, в разделе «Доступ», «SSH» или в письме хостинга. Для входа используйте пароль или SSH-ключ, который выбрали при создании сервера.

В сетевом экране хостинга разрешите входящий **TCP 443** для VPN. Сохраните доступ по SSH. При стандартной настройке SSH использует **TCP 22**.

## 2. Запустите установщик прямо на сервере

На своём компьютере откройте терминал или PowerShell и подключитесь по SSH. Замените `IP_СЕРВЕРА` публичным IPv4, а `root` — своим логином SSH.

```bash
ssh root@IP_СЕРВЕРА
```

После входа выполните команду ниже **на VPS**, подставив тот же IPv4. Она скачает скрипт с GitHub и запустит его после успешного скачивания.

```bash
curl -fL https://raw.githubusercontent.com/GubernatorovDev/AutoSep/773e9eebbbb366f5b3d325fd73a4248467817cff/install-personal-vpn.sh -o ~/install-personal-vpn.sh && \
sudo bash ~/install-personal-vpn.sh IP_СЕРВЕРА
```

Если `curl` не установлен, выполните `sudo apt update && sudo apt install -y curl ca-certificates` и повторите команду. Если вы вошли как `root` и `sudo` недоступен, выполните команды без него.

Когда установка завершится, откройте файл доступа.

```bash
sudo cat /root/personal-vpn-access.txt
```

В файле будут адрес панели, её логин и пароль, команда для открытия панели через SSH и персональная ссылка `vless://`.

## 3. Подключитесь по готовой ссылке

Установщик уже создал тестовый профиль. Ссылка находится в строке `Test profile:` файла `/root/personal-vpn-access.txt`. Для первого подключения достаточно этой ссылки.

1. Скопируйте всю ссылку, начиная с `vless://`.
2. Откройте [INCY](https://github.com/INCY-DEV/incy-platforms) или [Happ](https://www.happ.su/main/faq/adding-configuration-subscription) и добавьте профиль из буфера обмена.
3. Выберите добавленный профиль, включите подключение и откройте любой сайт для проверки.

## 4. Управляйте профилями в панели 3x-ui

Откройте панель, если хотите создать отдельную ссылку для другого устройства, отключить профиль или изменить его лимит.

1. На **своём компьютере** выполните команду SSH из файла доступа. При необходимости замените `root` своим логином SSH. Оставьте терминал открытым.
2. Откройте адрес панели из файла и войдите с логином и паролем **3x-ui**.
3. В **Inbounds → Personal VPN** добавьте клиента и скопируйте его ссылку через **Share**. Первый профиль называется `personal-test`.

Файл с доступом имеет права `0600`. Храните его на сервере. Персональная ссылка позволяет подключиться к вашему VPN.

Установщик использует [3x-ui v3.11.0](https://github.com/MHSanaei/3x-ui/releases/tag/v3.11.0). Для своего HTTPS-узла REALITY можно передать доменное имя вторым аргументом. Узел проверяется на TLS 1.3, HTTP/2 и соответствие сертификата. Если установка не завершилась, подробности остаются в `/root/personal-vpn-install.log`.
