# Установка личного VPN на VPS

Установщик разворачивает 3x-ui и создаёт один профиль VLESS + gRPC + REALITY. Он рассчитан на чистый VPS с Ubuntu 22.04 или 24.04 либо Debian 12 или 13, systemd и публичным IPv4. Поддерживаются x86_64 и aarch64.

1. В кабинете хостинга найдите публичный IPv4 и данные для входа по SSH. В сетевом экране хостинга разрешите входящий TCP 443 и сохраните доступ по SSH. Порт панели 2053 оставьте закрытым извне.
2. Скачайте [install-personal-vpn.sh](install-personal-vpn.sh). В терминале или PowerShell перейдите в папку загрузок и подставьте адрес VPS и свой логин SSH.

   ```bash
   scp install-personal-vpn.sh root@IP_СЕРВЕРА:~/
   ssh root@IP_СЕРВЕРА
   ```

3. Выполните команды на сервере.

   ```bash
   sudo bash ~/install-personal-vpn.sh IP_СЕРВЕРА
   sudo cat /root/personal-vpn-access.txt
   ```

   Если вы уже работаете как `root` и `sudo` недоступен, выполните команды без него.

4. На своём компьютере выполните команду SSH из файла, сохранив терминал открытым. Откройте указанный в файле адрес панели и войдите с логином и паролем 3x-ui.
5. Импортируйте ссылку `vless://` из файла в приложение с поддержкой VLESS + gRPC + REALITY. Ссылка также доступна в панели через **Inbounds → Personal VPN → personal-test → Share**.

Файл с доступом имеет права `0600`. Храните его на сервере. Ссылка `vless://` даёт доступ к профилю.

Установщик использует [3x-ui v3.11.0](https://github.com/MHSanaei/3x-ui/releases/tag/v3.11.0). Для своего HTTPS-узла REALITY можно передать доменное имя вторым аргументом. Узел проверяется на TLS 1.3, HTTP/2 и соответствие сертификата. Если установка не завершилась, подробности остаются в `/root/personal-vpn-install.log`.
